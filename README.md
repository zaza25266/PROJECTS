# Projects

A growing collection of **AI/ML projects, experiments, and engineering work** built while learning and exploring modern AI systems.

The repository covers everything from **data and classical machine learning to deep learning, LLMs, and production-oriented ML systems**.

### Areas

* **Machine Learning** — ML models, feature engineering, evaluation
* **Deep Learning** — neural networks and PyTorch
* **Computer Vision** — detection, classification, segmentation
* **NLP & LLMs** — Transformers, language models, embeddings
* **RAG & Agentic AI** — retrieval systems, AI agents, tool calling
* **Multimodal AI** — vision, language, and other modalities
* **Fine-Tuning** — model adaptation and parameter-efficient fine-tuning
* **Inference & Optimization** — efficient and scalable model serving
* **Distributed Training** — multi-GPU and distributed ML
* **MLOps** — deployment, experiment tracking, data/model versioning, monitoring
* **Data Engineering & Data Science** — data pipelines, analysis, statistics, and experimentation

New projects will be added here over time as I learn, build, and explore these areas.
